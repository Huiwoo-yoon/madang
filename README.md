# 전통놀이 마당

하나의 시작 화면에서 여러 전통놀이를 고르는 온라인 통합판입니다. 빌드 없이 정적 파일만으로 돌아갑니다.
`game/Ttakji`, `game/tuho`(이 컴퓨터 전용판)는 건드리지 않고 복사해서 만들었습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html`, `hub.css`, `hub.js` | 통합 시작 화면 (로그인/가입, 놀이 고르기, 종합 순위) |
| `api.js` | 모든 놀이가 같이 쓰는 계정·저장 (Supabase, 또는 config가 비었을 때 localStorage) |
| `pixel.js` | 모든 놀이가 같이 쓰는 도트 그림 (한복 입은 캐릭터 14명 + 대마왕·알바, 한옥·궁궐 배경). 그림 파일 없이 코드로 그림 |
| `config.js` | Supabase 주소와 공개 키 (타자연습 `type_game` 프로젝트를 같이 씀) |
| `schema.sql` | DB 표 만들기 |
| `ttakji/`, `tuho/` | 놀이 하나당 폴더 하나 (`index.html`, `game.js`, `style.css`) |
| `sudoku/`, `wordcross/` | 미니게임 하나당 폴더 하나. `puzzles.js`(문제)와 `engine.js`(규칙)는 받은 그대로, `app.js`만 마당에 맞게 고침 |
| `scary/` | 무서운 수학: `problems.js`(받은 문제 그대로), `scary.js`(5분 타이머·팝업·정답 확인), `scary.css` |
| `mini.js`, `mini.css` | 미니게임 공통: 로그인 확인, 하루 한 번 보상, 모양 |

## 무엇이 공용이고 무엇이 따로인가

| | 저장 위치 |
|---|---|
| 포인트, 가진 캐릭터, 지금 쓰는 캐릭터 | **공용** — `madang_profiles` (계정당 한 줄) |
| 강화·전설·소모품·집·생명 아이템, 알바, 레벨, 트로피 | **놀이마다 따로** — `madang_saves` (계정 × 놀이당 한 줄) |

캐릭터는 한 번 사면 모든 놀이에서 쓸 수 있습니다. 캐릭터의 잠금 조건(레벨·트로피)은 사는 놀이의 레벨·트로피로 봅니다.

## 미니게임 (스도쿠, 워드크로스)
- 미니게임마다 **하루에 한 번**만 보상을 받습니다. 다 풀면 그날은 잠기고, 다음 날 새 문제가 나옵니다 (문제는 날짜 순서대로 돌아가며 나옴).
- 풀다가 나가도 그날 안에는 이어서 할 수 있습니다 (그 브라우저에 저장).
- 보상: 스도쿠 애기 100 · 쉬운 200 · 중간 500 · 어려운 1000 · 최고 2000, 워드크로스 한글 300 · 영어 500.
  힌트를 한 번 쓸 때마다 10%씩 줄고 최소 30%는 받습니다. 숫자는 각 `app.js` 맨 위의 `REWARD` / `LANGS`에 있습니다.
- 포인트는 공용 프로필에 더해지고, 순위(트로피·레벨)에는 들어가지 않습니다.
- 받은 날짜는 `madang_saves`의 `game = 'sudoku' / 'wordcross'` 줄에 적습니다. DB는 고칠 필요가 없습니다.
- 날짜는 기기 시계로 봅니다. 시계를 바꾸면 하루에 여러 번 받을 수 있습니다 (서버에서는 막지 않음).

## 무서운 수학 (한밤의 문제집)
- 딱지치기·투호를 **5분** 하면(두 놀이의 시간을 합쳐서 셈) 귀신이 나타나 50문제 중 하나를 무작위로 냅니다. 미니게임과 시작 화면에서는 안 나옵니다.
- **주관식**이고, 맞힐 때까지 놀이를 누를 수 없습니다. 새로고침하거나 다른 놀이로 가도 같은 문제가 다시 뜹니다 (계정별로 그 브라우저에 저장).
- 정답은 보통 "답에 든 숫자가 같으면" 맞습니다 (`30개` ← `30`). 이름·문 고르기처럼 숫자가 아닌 9문제는 `scary.js`의 `RULES`에 따로 적혀 있습니다.
- 한 번 틀리면 힌트가 나오고, 3번 틀리면 "다른 문제로 바꾸기"가 나옵니다. 맞히면 풀이와 뒷이야기를 보여 줍니다.
- 문제가 떠 있는 동안에도 알바는 계속 포인트를 벌고, 팝업에 지금 포인트가 보입니다.
- 보스전 중에는 나오지 않고 끝난 뒤에 나옵니다. 화면을 안 보고 있을 때(다른 탭)는 시간이 가지 않습니다.
- 시간·횟수는 `scary.js` 맨 위의 `PERIOD`(초), `SWAP_AFTER`에서 바꿉니다. 포인트는 주지 않습니다.

## 온라인으로 올리기

### 1. DB 만들기 (한 번만)
Supabase 대시보드 → `type_game` 프로젝트 → **SQL Editor**에 `schema.sql`을 통째로 붙여 넣고 **Run**.
타자연습·예전 딱지치기 표는 건드리지 않습니다. 계정도 따로입니다 (마당 아이디는 `아이디@madang.game`).

**이걸 하기 전에 가입하면 안 됩니다.** 표가 없어서 가입이 중간에 실패합니다.

### 2. 웹에 올리기
<https://app.netlify.com/drop> 에 `madang` 폴더를 통째로 끌어다 놓으면 주소가 바로 나옵니다.
고친 뒤에는 Netlify 사이트의 **Deploys** 화면에 폴더를 다시 끌어다 놓으면 같은 주소로 갱신됩니다.

## 고친 뒤에 꼭 할 일: 버전 숫자 올리기
html 파일들은 `hub.js?v=20261002d`처럼 버전을 붙여서 js·css를 부릅니다. 브라우저가 예전 파일을 10분쯤 기억하고 있어서,
버전을 안 올리면 새 화면과 옛 코드가 섞여 "새로 넣은 게 안 보이는" 일이 생깁니다.
js나 css를 고쳤으면 html 다섯 개(`index.html`, `ttakji/`, `tuho/`, `sudoku/`, `wordcross/`의 `index.html`)의 `?v=` 값을 전부 새 값으로 바꾸세요.

## 놀이를 새로 추가할 때
1. `madang/새놀이/` 폴더를 만든다 (`tuho/`를 복사해서 시작하면 편함).
2. 그 놀이 `game.js` 맨 위의 `const GAME = '새놀이'`를 바꾼다. 이 값이 DB의 `game` 값이 된다.
3. `hub.js`의 `GAMES`에 한 줄 추가한다.

DB는 고칠 필요가 없습니다. 놀이 쪽에서 쓰는 함수는 `API.restore()`, `API.loadGame(GAME)`,
`API.save(GAME, { points, character, chars, trophies, level, data })`, `API.leaderboard(GAME)` 네 개입니다.

## 알아 둘 점
- 비밀번호는 Supabase가 해시로 보관합니다. 잊어버리면 Supabase 대시보드
  **Authentication → Users**에서 `아이디@madang.game` 사용자의 비밀번호를 바꿔 줄 수 있어요.
- 저장은 3초에 한 번씩 모아서, 그리고 창을 닫거나 다른 탭으로 갈 때 합니다. 보스를 이기면 바로 저장해요.
- **두 놀이를 탭 두 개로 동시에 열면 안 됩니다.** 포인트를 "지금 값"으로 덮어써서, 나중에 저장한 탭의 포인트만 남습니다.
- 알바는 그 놀이 창이 열려 있을 때만 일합니다.
- 포인트가 공용이라, 한 놀이에서 많이 번 사람은 새 놀이의 아이템을 금방 살 수 있습니다.
  레벨(경험치)은 직접 맞힌 기본 점수로만 오르므로 순위는 돈으로 살 수 없습니다.

### 순위 조작 막기
게임 계산은 브라우저에서 돌아가서 완벽하게 막을 수는 없지만, 서버(`schema.sql`의 `madang_save_guard`)가 쉬운 조작은 막습니다.
- 새 계정은 포인트 0, 놀이마다 트로피 0, 레벨 1로 시작
- 트로피는 한 번에 1개씩만, 1분에 1개보다 빨리 늘 수 없고, 줄어들지 않음
- 레벨은 1~20

## 투호가 전용판과 다른 점
딱지치기 온라인판과 같은 규칙을 적용했습니다.

| | 전용판 (`game/tuho`) | 마당판 |
|---|---|---|
| 레벨 경험치 | 번 포인트 전부 | **직접 넣은 항아리의 기본 점수만** (1 · 2 · 3 · 5). 무지개 화살은 2배 |
| 강화 아이템 가격 | 기본값 × (단계+1) | 기본값 × **1.6^단계** |
| 알바 업그레이드 | 50 × 레벨 | 50 × **1.5^(레벨-1)** |
| 대마왕 | 항상 같음 | **트로피를 딸 때마다 세짐** (하트 3→최대 8, 초록 구간 9%→최소 5%) |
